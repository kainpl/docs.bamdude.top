# Усунення проблем AI

Зіставляйте стан, код помилки й журнал клієнта. Не вставляйте в чат API-ключ, заголовок авторизації, cookie чи неприхований пакет підтримки. Штатний шлях описано в [підключенні](setup.md).

| Симптом | Що перевірити / наступна дія |
|---|---|
| Сервер вимкнений / `/mcp` дає 404 | Увімкніть MCP і збережіть. Використовуйте точно `/mcp`, без слеша наприкінці. `/mcp/` навмисно повертає 404 без redirect. |
| Сервер недоступний після старту | Встановіть актуальні залежності BamDude звичним оновленням і перезапустіть. Потрібна нова бібліотека MCP; решта застосунку може стартувати без неї. |
| Утримується після restore / читачі ще зупиняються | Завершіть відновлення й перезапустіть BamDude за вказівкою. Перемикач enable не обходить утримання restore. |
| `invalid_endpoint` | Поза loopback використовуйте HTTPS і точний `/mcp`. У збірках з опцією HTTP для довіреної LAN приватна HTTP-адреса потребує явних [дозволів сервера й конектора](setup.md#server-address). Приберіть user info, query й fragment. |
| `network_or_tls_error` | Перевірте DNS/IP, порт, досяжність, ім’я в сертифікаті та довіру. Хмарний конектор не бачить LAN лише тому, що його інтерфейс працює локально. |
| `redirect_forbidden` | Задайте одразу кінцеву адресу `/mcp`. Приберіть redirect HTTP→HTTPS чи на slash у proxy; конектор не пересилає ключ через redirect. |
| `unauthorized` / 401 | Замініть прострочений, вимкнений чи відкликаний ключ у налаштуваннях клієнта. Не запускайте OAuth discovery й не кладіть ключ у URL. |
| `forbidden` / 403 | Перевірте прапорці MCP/читання стану, активного власника й права, точний дозволений хост та Origin, якщо він надсилається. Не розширюйте права навмання. |
| `incompatible_contract` | Оновіть пакет і сервер до сумісних версій. Не міняйте номери контрактів вручну. |
| Пакет відсутній або несумісний | Використайте відповідні build/release assets. Сервер відмовляє за неправильних хешів, версій чи вмісту skill/guide. Для встановлення із сирців потрібен крок збирання AI-пакетів. |
| `response_too_large` | Попросіть менше даних або меншу сторінку. Локальний конектор повертає обмежену помилку й лишає з’єднання придатним. |
| `busy`, `rate_limited`, timeout | Зменште паралельність чи зачекайте. Конектор не повторює запити нескінченно; серверні ліміти читання зберігаються. |

## Самопідписаний сертифікат, особливо за IP

1. Отримайте правильний PEM-файл CA у того, хто налаштовує HTTPS ферми.
2. Виберіть його в **Trusted CA file** локального розширення/плагіна.
3. Звертайтеся за адресою із сертифіката. Сертифікат для `farm.local` не підтверджує `192.0.2.10`; для звернення за цією IP вона повинна бути явно в subject alternative names.
4. Після заміни сертифіката/CA оновіть явну довіру й перезапустіть MCP-підключення. Інший недовірений сертифікат має бути відхилений.

**Не вимикайте перевірку TLS**, зокрема через `NODE_TLS_REJECT_UNAUTHORIZED=0`. Конектор відмовляє з таким налаштуванням. Хмарний remote connector провайдера — не те саме, що явна довіра в цьому локальному конекторі.

## Під час запуску клієнта ферма була офлайн

Локальний конектор завершується при збої старту, а не повторює спроби у фоні. Коли ферма повернеться, перезапустіть клієнт або його MCP-підключення. Пакет може лишатися встановленим, хоча з’єднання не працює.

## Сервер готовий, але звернення клієнта не спостерігали

Запустіть capabilities/guide в обраному клієнті, виберіть той самий ключ у BamDude й натисніть **Перевірити підключення**. Перевірте фактичний мережевий маршрут і ключ клієнта. REST `last_used` не доводить MCP-запит. Після перезапуску BamDude позначка порожня до наступного авторизованого MCP-звернення.

Позначка не доводить ні правильного висновку діагностики, ні встановлення skill. За потреби встановіть skill окремо. Якщо інструмент недоступний, поясніть обмеження, а не замінюйте його довільними REST, SQL чи командами пристрою.

## Що безпечно додати до звіту

Версії BamDude й клієнта, ОС, формат пакета, локальний чи хмарний клієнт, код помилки, стан сервера та час спроби. За потреби замініть приватні хости/IP. Не додавайте ключ. Сам успішний SDK-тест чи перевірка manifest не доводить підтримку названого клієнта.
