# Додатки

BamDude — self-hosted сервер. Додатки з’єднують його із застосунками та обладнанням на вашому комп’ютері. BamDude Bridge передає файли слайсера й друкує USB-етикетки, а пакети AI-асистентів підключають вашого помічника до окремо ввімкненого MCP лише для читання.

<div class="grid cards" markdown>

-   :material-bridge:{ .lg .middle } **BamDude Bridge**

    ---

    Windows-застосунок у треї: приймає наслайсені плити просто з кнопки *Send to…* у Bambu Studio і друкує на USB-принтерах етикеток Niimbot із черги BamDude.

    [:octicons-arrow-right-24: Документація](bridge.md)

-   :material-brain:{ .lg .middle } **Obico ML**

    ---

    Окремий контейнер для AI-виявлення збоїв друку. Встановлення й оновлення лише ML API, без повного стека Obico.

    [:octicons-arrow-right-24: Встановлення й оновлення](obico-ml.md)

</div>

## AI-асистенти — попередня версія в розробці

MCP-сервер працює всередині BamDude. Пакет клієнта й skill встановлюються в асистента, не на принтер. Почніть із [посібника AI-асистентів](ai-assistants/index.md); встановлення й підтримка клієнта перевіряються окремо.
