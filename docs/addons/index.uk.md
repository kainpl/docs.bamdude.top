# Додатки

BamDude — self-hosted сервер, і дещо структурно недосяжне з контейнера: локальний диск твоєї робочої станції, USB-залізо на столі. Додатки — окремі застосунки-компаньйони, що закривають саме ці прогалини й говорять із сервером через його звичайний API. Це мости, а не другі продукти: без власних баз даних і без окремого стану, який довелося б синхронізувати.
